## 🧠 Engineering Principles

I try to build software around a few simple principles:

**Useful over flashy**
Solve a real problem before adding unnecessary complexity.

**Local-first where practical**
Keep data and important functionality close to the user whenever possible.

**Documentation is part of the product**
Installation, architecture, usage, limitations, and release notes should be understandable.

**Reproducible development**
A project should be reasonably easy for another developer to build, test, and understand.

**Continuous improvement**
Prototype → validate → test → document → release → improve.
